Бул сабак SELECT сурамдарына арналат: SELECT, WHERE жана ORDER BY менен таблицалардан так керектүү маалыматты алыңыз.

<Definition term="SELECT сурамдары">
  SELECT, WHERE жана ORDER BY менен таблицалардан так керектүү маалыматты алыңыз.
</Definition>

## Негизги идеялар

### SQL кантип эмес, эмнени сүрөттөйт

Сиз SELECT Name FROM Students WHERE Year = 12 жазасыз, ал эми маалымат базасы саптарды кантип табууну өзү чечет — SQL декларативдүү. WHERE саптарды чыпкалайт, ORDER BY аларды сорттойт, ал эми JOIN ачкычтар аркылуу таблицаларды бириктирет. Сиз каалаган жыйынтыкты сүрөттөгөндүктөн, бир эле сурам он сапта да, он миллиондогондо да иштейт.

### Ачкычтар маалыматтын жоголушуна жол бербейт

Негизги ачкыч ар бир сап так бир жолу табылышына кепилдик берет — ал болбосо 'Smith' аттуу эки кардарды айырмалоого болбой калат. Тышкы ачкычтар андан соң таблицаларды байланыштырат: буйрутма сабы кардардын бүт дарегин көчүргөндүн ордуна кардардын IDсин сактайт, ошондуктан дарек өзгөрүү бир гана жерде жаңыртылат. Бул ишенимдүү маалыматтын негизи.

**Термин — сурам:** Маалымат базасына SQL менен берилген суроо — эң белгилүүсү дал келген саптарды алган SELECT оператору.

<WorkedExample title="Талданган мисал: SELECT сурамдары">
  Students таблицасынын ID, Name, Year мамычалары жана (1, Priya, 12), (2, Tom, 11), (3, Aisha, 12), (4, Leo, 10) саптары бар. 12-класстын окуучуларынын аттарын алфавит боюнча тизмелөөчү сурам жазыңыз.

  Бизге аттар гана керек, Students таблицасынан: SELECT Name FROM Students.
  12-класстын саптары гана калсын: WHERE Year = 12 кошуңуз. Бул Priya менен Aishaга дал келет.
  Алфавит боюнча сорттоңуз: ORDER BY Name кошуңуз. Aisha Priyaдан мурун келет.
  Толук сурам: SELECT Name FROM Students WHERE Year = 12 ORDER BY Name;.

  **Жооп:** Сурам эки сап кайтарат: алгач Aisha, андан соң Priya.
</WorkedExample>

<ImportantNote title="Кеңири таралган каталар">
  - **UPDATE же DELETEте WHERE шартын унутуу** Түзөтүү: WHEREсиз UPDATE Students SET Year = 13 ар бир сапты өзгөртөт — ар дайым WHEREни алгач жазыңыз же ошол эле шарт менен SELECT аркылуу текшериңиз.
  - **Бир эле фактыны эки таблицада сактоо** Түзөтүү: бир жолу сактап, тышкы ачкыч менен байланыштырыңыз — кайталанган маалымат бир көчүрмөсү гана жаңыртылганда шайкешсиз болуп калат.
</ImportantNote>
