Блок-схема — пландын сүрөтү. Эч ким код жазганга чейин программа эмне кылышы керектигин чиет — стандарттуу фигуралар менен, ошондо чиймени окуган ар бир адам аны бирдей түшүнөт.

<Definition term="Блок-схема">
  Алгоритмдин кадамдарын жебелер менен бириктирилген стандарттуу фигуралардын жардамы менен ирети менен көрсөткөн диаграмма.
</Definition>

## Негизги идеялар

### Алгач кагазга пландаштыр

Код майда-чүйдө: бир туура эмес белги — эч нерсе иштебей калат. Блок-схема синтаксис менен алышуудан мурда *логиканы* туура курууга мүмкүндүк берет. Эгер план кагазда туура эмес болсо, коддо да туура эмес болот — ошондуктан программисттер алгач чийишет, анан жазышат.

### Баары макулдашкан фигуралар

Үйрөнө турган фигуралар саналуу гана, жана алар бүт дүйнөдө бирдей:

- **Овал** — баштоо жана токтотуу. Ар бир блок-схема БАШТАЛДЫ овалы менен ачылып, БҮТТҮ овалы менен жабылат.
- **Тик бурчтук** — процесс. Компьютер аткарган нерсе, мисалы «суммага 1 кош».
- **Параллелограмм** (кыйшайтылган тик бурчтук) — киргизүү же чыгаруу. «Упайды оку» же «жыйынтыкты басып чыгар».
- **Ромб** — чечим (шарт). Ооба/жок жообу бар суроо, мисалы «упай 50 же андан көпбү?».
- **Жебелер** — агым сызыктары. Кайсы кадам кийин келерин көрсөтөт, ошондуктан ар бир жебенин так багыты болушу керек.

**Негизги термин — алгоритм:** Маселени чечүү үчүн кадам-кадам берилген көрсөтмөлөрдүн жыйындысы. Блок-схема алгоритмди *көрсөтүүнүн* бир жолу; код аны *жазуунун* жолу.

### Китептеги классика: милден километрге

Окуучулар алгач чийген блок-схемалардын бири милди километрге айландырат:

<CodeBlock lang="Блок-схема кадамдары">
START → INPUT distanceMiles → km = distanceMiles * 1.609 → OUTPUT km → STOP
</CodeBlock>

distanceMiles = 10 менен байка: параллелограмм 10ду окуйт, тик бурчтук 10 × 1,609 = 16,09ду эсептейт, экинчи параллелограмм 16,09ду чыгарат. **Байкоо жүргүзүү** — блок-схеманы чыныгы маанилер менен кадам-кадам ээрчүү — код жазганга чейин алгоритмдин иштешин далилдөөнүн жолу.

### Андан ары: жетилердин көбөйтүү жадыбалы

Ошол эле фигура кеңейет. Бул блок-схема сан киргизип, анын жетилерге көбөйтүү жадыбалын басып чыгарат:

<CodeBlock lang="Блок-схема кадамдары">
START → INPUT number → answer = number * 7 → OUTPUT number & " * 7 = " & answer → STOP
</CodeBlock>

number = 3 менен: answer 21 болот, чыгаруу «3 * 7 = 21» деп окулат. & белгиси санды, текстти жана жоопту бир сапка бириктирет. Бир киргизүү, бир процесс, бир чыгаруу — бар болгон эң жөнөкөй пайдалуу алгоритм.

<WorkedExample title="Блок-схеманы байка">
  Тест жыйынтыгы үчүн блок-схема: БАШТАЛДЫ → INPUT «упайды оку» → DECISION «упай ≥ 50би?» → Ооба → OUTPUT «Өттү басып чыгар» → БҮТТҮ; Жок → OUTPUT «Өтпөдү басып чыгар» → БҮТТҮ.

  Упай 65. Жебелерди ээрчи: БАШТАЛДЫ, 65ти оку, «65 ≥ 50би?» деп сура — ооба — демек Ооба жолун танда, «Өттү» басып чыгар, БҮТТҮ.

  **Жооп:** Блок-схема «Өттү» чыгарат. Упай 40 болсо, Жок жолу «Өтпөдү» басып чыгармак.
</WorkedExample>

<ImportantNote title="Кеңири таралган каталар">
  - **Багыты жок жебелер** Түзөтүү: ар бир жебе бир жакка багытталышы керек — так багыты жок жебе окурманды кайсы кадам кийин келерин болжоого мажбурлайт.
  - **БАШТАЛДЫ же БҮТТҮ жок** Түзөтүү: ар бир блок-схема БАШТАЛДЫ овалы менен ачылып, БҮТТҮ овалы менен жабылат, ошондо окурман алгоритм кайда башталып, кайда бүтөрүн билет.
  - **Киргизүү/чыгаруу үчүн тик бурчтук** Түзөтүү: «упайды оку» — бул киргизүү, демек анын орду параллелограммда — тик бурчтуктар процесстер үчүн гана.
</ImportantNote>
