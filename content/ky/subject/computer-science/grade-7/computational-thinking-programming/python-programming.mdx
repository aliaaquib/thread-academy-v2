Python — дүйнөдөгү эң популярдуу тилдердин бири жана баштагандар үчүн эң ыңгайлууларынын бири. Блок-схемаларда пландаганыңдын баары (ырааттуулук, тандоо) эми чыныгы, жазылган кодго айланат.

<Definition term="Өзгөрмө">
  Программаң колдоно жана кийин өзгөртө ала турган маанини сактаган аталган куту.
</Definition>

## Негизги идеялар

### Чыгаруу жана сактоо

`print()` экранга бир нерсе көрсөтөт. Өзгөрмө `=` менен кийин колдонуу үчүн бир нерсени сактайт:

<CodeBlock lang="Python">
print("Hello, world!")
score = 0
print(score)
</CodeBlock>

Бул `Hello, world!` басып чыгарат, 0ду `score` ичинде сактайт, анан `0` басып чыгарат. Тырмакчадагы текст **сап (string)** деп аталат; сандарга тырмакчанын кереги жок.

### Киргизүү — бир сыр менен

`input()` колдонуучудан бир нерсе терүүнү сурайт. Сыр: тергениңдин баары дайыма **сап** болуп кайтат — сандар да. Аны менен математика кылуу үчүн адегенде өзгөрт:

<CodeBlock lang="Python">
colour = input("Enter a colour")
print(colour)
</CodeBlock>

«blue» тер — blue басып чыгарат. Эми сандар менен:

<CodeBlock lang="Python">
age_text = input("Your age: ")
age = int(age_text)
next_year = age + 1
print(next_year)
</CodeBlock>

`int()` «12» текстин 12 санына айландырат. Болбосо `age + 1` бузулат — 1ди текстке кошо албайсың.

### Маалымат типтери: маанилердин төрт түрү

Pythonдогу ар бир маанинин типи бар, ал эми тип аны менен эмне кыла алаарыңды чечет:

- **Бүтүн сан** — бүтүн сан: 120, 0, -7.
- **Чыныгы сан** (float) — бөлчөк бөлүгү бар сан: 21.3, 1.609.
- **Белги** — бир белги: '!', 'V', 'o'.
- **Сап** — бир же бир нече белги: "house", "Victoria Ellis".

Бүтүн сан — бүтүн сан; чыныгы сандын бөлчөк бөлүгү болушу мүмкүн. Белги бирөө гана; сап — бирөө же бир нече. Аларды чаташтыруу каталардын классикалык булагы — «10» (сап) менен 10 (бүтүн сан) окшош көрүнөт, бирок башкача жүрүм-турум көрсөтөт.

### Атоо эрежелери: жарактуу жана жараксыз идентификаторлор

Өзгөрмө аттарынын (идентификаторлордун) катуу эрежелери бар:

- Жарактуу: colour, totalCost, numA, result
- Жараксыз — сандан башталат: 2ndPlace
- Жараксыз — боштук же чекит бар: my score, my.score
- Жараксыз — корголгон сөз: print, if
- Жараксыз — дефис бар: my-score

Эрежени бузсаң, Python атты кабыл албайт. Жакшы аттар маанилүү да: totalCost сенин кодуңду окуган башка адам үчүн xтен жакшы.

### Коддогу тандоо: if-буйруктары

Блок-схемадагы ромб эсиңдеби? Pythonдо ал мындай көрүнөт:

<CodeBlock lang="Python">
score = 65
if score >= 50:
    print("Pass")
else:
    print("Fail")
</CodeBlock>

Шарт «барабар» үчүн `==` колдонот (жалгыз `=` сактоого аракет кылат, салыштырбайт). Анын астындагы чегинүү менен жазылган саптар шарт чын болгондо гана иштейт. Чегинүү Pythonдо жасалга эмес — синтаксистин бир бөлүгү.

Өзүң байка — кодду оңдо да, «Иштет» баскычын бас:

  title="Байка: сенин алгачкы Pythonуң"

  initialCode={`print("Hello!")

<WorkedExample title="Жаш текшергичти байка">
  Код: `age = int(input("Age: "))` анан `if age >= 13: print("Teen")` else `print("Child")`. Колдонуучу 10 терет.

  Сап-сап: input «Age: » көрсөтөт, колдонуучу 10 терет — «10» текст катары. int() аны 10 санына айландырып, age ичинде сактайт. `10 >= 13` шарты жалган, ошондуктан чегинүү менен жазылган print("Teen") өткөрүлүп жиберилет; анын ордуна else бутагы иштейт.

  **Жооп:** Программа «Child» басып чыгарат. Колдонуучу 15 терсе, шарт чын болмок жана «Teen» басып чыгармак.
</WorkedExample>

<WorkedExample title="Бөлүү программасын оку">
  Бул программа колдонуучудан эки сан алат, биринчисин экинчисине бөлөт жана жоопту басып чыгарат:

<CodeBlock lang="Python">
num1 = int(input("First number: "))
num2 = int(input("Second number: "))
answer = num1 / num2
print(answer)
</CodeBlock>

  20 жана 4 менен байка: num1 = 20, num2 = 4, answer = 20 / 4 = 5.0, 5.0 басып чыгарат.

  **Жооп:** 5.0 басып чыгарат — жана чыныгы сан жыйынтыкка көңүл бур: Pythonдо бөлүү бүтүн сандар үчүн да ондук сан берет.
</WorkedExample>

<ImportantNote title="Кеңири таралган каталар">
  - **== ордуна =** Түзөтүү: = маани сактайт (score = 65); == салыштырат (if score == 65:). if ичинде = колдонуу ката.
  - **inputто int() унутуу** Түзөтүү: input() дайыма сап кайтарат — ар кандай арифметикадан мурда аны int() менен ороп, болбосо программа бузулат.
  - **Чегинүү туура эмес** Түзөтүү: if астындагы саптар чегинүү менен жазылышы керек (адатта 4 боштук). Python кайсы саптар ifке таандык экенин чегинүү менен чечет.
</ImportantNote>
