  <li>үлгү таануу сыяктуу негизги терминдерди так колдон</li>
  <li>Үйрөнгөндөрүңдү жаңы мисалдарга жана суроолорго колдон</li>
  <li>Бул темада окуучулар кетирген кеңири таралган каталардан сактан</li>
</LearningObjectives>

Маселени жакшы чечкендер ар бир маселени таптакыр жаңыдай кабыл алышпайт. Алар буга чейин көргөндөрүн издешет — жакшы программисттер да блок-схемаларында ошондой кылышат.

<Definition term="Үлгү таануу">
  Көп чечим ойлоп табуунун ордуна бир чечимди кайра колдонуу үчүн маселендеги кайталанууну же окшоштукту байкоо.
</Definition>

## Негизги идеялар

### Кайталанууну көр

Үч коноктун ар бирине бирден кечеге чакыруу басып чыгарган блок-схеманы элестет. «Атын басып чыгар, датасын басып чыгар, жерин басып чыгар» деген кадамдар кайра-кайра чыгат. Бул кайталануу — үлгү, ал эми үлгүлөр — белги: бул кадамдар тобу өз атына татыктуу.

### Кошумча программалар: ата, кайра колдон

**Кошумча программа** — бир ишти аткарган, аталган кадамдар тобу. Негизги блок-схема аны керек болгон жерде *чакырат*, атайын символ менен: кош вертикалдуу сызыктуу тик бурчтук (алдын ала аныкталган процесс символу). Кошумча программа бүткөндө агым чакырылган жерине кайтат.

### Кошумча программалар киргизүү маалымат ала алат

Кошумча программа ар бир чакырылышында маани ала алат — ал **параметр** деп аталат. `greet(name)` ага берилген аттан кийин «Салам, » деп басып чыгарат: greet("Asha") «Салам, Asha» басып чыгарат, greet("Omar") «Салам, Omar» басып чыгарат. Кадамдар бирдей, жыйынтык башка.

### Эмне үчүн аракеттенебиз? Үч себеп

1. **Убакытты үнөмдө** — кадамдарды беш жолу көчүргөндүн ордуна бир жолу жаз.
2. **Бир жолу тесттен өткөр** — кошумча программаны бир жолу гана тесттен өткөрүү жетиштүү; ар бир чакыруу буга чейин иштегени белгилүү кадамдарды кайра колдонот.
3. **Бир жолу оңдо** — кошумча программанын ичинде оңдолгон ката ал чакырылган бардык жерде оңдолгон болот.

### Чыныгы мисал: addNumbers

<CodeBlock lang="Блок-схема кадамдары">
SUB-ROUTINE addNumbers: START → INPUT num1 → INPUT num2 → total = num1 + num2 → OUTPUT total → RETURN
MAIN: START → ... → CALL addNumbers → ... → CALL addNumbers → ... → STOP
</CodeBlock>

Кошумча программанын **идентификатору** бар — анын аты, addNumbers. Негизги алгоритм сумма керек болгон жерде аны ушул ат менен чакырат, анан токтоп калган жеринен улантат. Кошуу логикасын бир жолу чиесиң, бир жолу тесттен өткөрөсүң жана каалаганча чакырасың.

### Кошумча программалар киргизүү маалымат ала алат

<WorkedExample title="Чакырууларды байка">
  Негизги агым: БАШТАЛДЫ → print_inviteти чакыр → print_inviteти чакыр → БҮТТҮ. print_invite кошумча программасы бир чакырууну басып чыгарып, кайтат.

  Байкоо: БАШТАЛДЫ, print_inviteти чакыр (ичине секир, чакырууну басып чыгар, КАЙТ менен негизги агымга кайт), print_inviteти кайра чакыр (чакырууну басып чыгар, КАЙТ), БҮТТҮ.

  **Жооп:** Кадамдар бир жолу гана жазылганына карабастан эки чакыруу басып чыгарылат. Үчүнчү конок кошуу — кадамдарды кайра жазуу эмес, бир чакыруу кошуу дегенди билдирет.
</WorkedExample>

<ImportantNote title="Кеңири таралган каталар">
  - **Чакыргандын ордуна кадамдарды көчүрүү** Түзөтүү: ошол эле кадамдарды үч жолу чаптоо — катаны үч жолу оңдоо дегенди билдирет — анын ордуна кошумча программаны чакыр.
  - **Так эмес ат** Түзөтүү: кошумча программаны анын ишине жараша ата — thing1 эмес, print_invite — ошондо негизги агым көрсөтмөдөй окулат.
  - **Анын бүтүшү керектигин унутуу** Түзөтүү: кошумча программа КАЙТ менен бүтөт (чакырганга кайтып), БҮТТҮ менен эмес — БҮТТҮ бүт программаны бүтүрмөк.
</ImportantNote>
