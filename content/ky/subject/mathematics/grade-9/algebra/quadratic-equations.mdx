## x чарчыга көтөрүлгөндө

**Квадраттык теңдемеде** `x²` бар (бирок жогорку даражалар жок). Анын графиги — ийри сызык, парабола, ошондуктан квадраттык теңдемелердин **эки** чечими болушу мүмкүн: ийри сызык x огун эки жолу кесип өтүшү мүмкүн.

<Definition term="квадраттык теңдеме">
  **Квадраттык теңдеме** — белгисиздин эң жогорку даражасы 2 болгон теңдеме,
  мисалы `x² + 5x + 6 = 0` же `2x² − 8 = 0`.
</Definition>

## Көбөйтүүчүлөргө ажыратуу менен чечүү

Негизги ыкма: **эгер эки нерсе көбөйтүлүп нөл чыкса, алардын бири нөл.** Ошондуктан:

1. `... = 0` түрүнө келтир.
2. Квадраттык теңдемени көбөйтүүчүлөргө ажырат.
3. Ар бир кашааны нөлгө барабарлап чеч.

<WorkedExample title="Иштелген мисал">
  `x² + 5x + 6 = 0`ту чеч.

  ```maths
  x² + 5x + 6 = 0
  (x + 2)(x + 3) = 0      көбөйтүүчүлөргө ажырат: суммасы 5ти, көбөйтүндүсү 6ны берген кайсы жуп?
  x + 2 = 0  же  x + 3 = 0
  x = −2  же  x = −3
  ```

  `x = −2`ни текшер: `4 − 10 + 6 = 0` ✓
</WorkedExample>

`x² + bx + c`ти көбөйтүүчүлөргө ажыратуу үчүн **көбөйтүндүсү cни**, **суммасы bни** берген эки санды тап. `x² + 5x + 6` үчүн: 2 жана 3 (2 × 3 = 6, 2 + 3 = 5).

## Квадраттык теңдеменин формуласы

Ар бир квадраттык теңдеме ыңгайлуу ажыратыла бербейт. **Квадраттык теңдеменин формуласы** *каалаган* квадраттык теңдемени `ax² + bx + c = 0` чечет:

<Formula label="Квадраттык теңдеменин формуласы">
  x = (−b ± √(b² − 4ac)) / 2a
</Formula>

<WorkedExample title="Иштелген мисал">
  `2x² + 5x − 3 = 0`ту чеч, бул жерде `a = 2`, `b = 5`, `c = −3`.

  ```maths
  x = (−5 ± √(25 − 4(2)(−3))) / 4
  x = (−5 ± √(25 + 24)) / 4
  x = (−5 ± 7) / 4
  x = 0.5  же  x = −3
  ```
</WorkedExample>

<ImportantNote title="Дискриминант">
  Чарчы тамырдын астындагы бөлүк, `b² − 4ac`, **дискриминант** деп аталат.
  Эгер ал оң болсо, эки чечим бар; нөл болсо, бир кайталанган чечим; терс болсо, чыныгы чечимдер жок.
</ImportantNote>

## Көнүгүүлөр

<PracticeQuestions>
  <PracticeItem question="Чеч: x² − 9 = 0." hint="Кайра түз же эки чарчынын айырмасы катары ажырат.">
    `x² = 9`, демек `x = 3` же `x = −3`. (Же `(x − 3)(x + 3) = 0`.)
  </PracticeItem>
  <PracticeItem question="x² + 7x + 12 = 0ту көбөйтүүчүлөргө ажыратып чеч." hint="Көбөйтүндүсү 12ни, суммасы 7ни берген эки санды тап.">
    `(x + 3)(x + 4) = 0`, демек `x = −3` же `x = −4`.
  </PracticeItem>
  <PracticeItem question="Квадраттык теңдеменин формуласы менен x² + 4x + 1 = 0ту чеч. Жоопторду 2 ондук орунга чейин бер." hint="a = 1, b = 4, c = 1.">
    `x = (−4 ± √12)/2 = −2 ± √3`, демек `x ≈ −0.27` же `x ≈ −3.73`.
  </PracticeItem>
</PracticeQuestions>
