  <li>Функциялар жана графиктер түшүнүгүнө өз сөзүң менен аныктама бер жана түшүндүр</li>

  <li>Бул темада окуучулар кетирген типтүү каталардан сактан</li>

Таза математика түзүмдү анын өзү үчүн изилдейт — жана планета орбиталарынан тартып компьютердик графикага чейин баарын сүрөттөп чыгат экен. Бул жерде функциялар, тизимдер жана дифференциялоо интегралдоо сени өзгөрүүнү так моделдөөчү куралдар менен камсыз кылат.

Бул сабак Функциялар жана графиктер жөнүндө: аныкталуу облусу, маанилер облусу, курама жана тескери функциялар, жана функция графиктерин өзгөртүү.

<Definition term="Функциялар жана графиктер">
  Аныкталуу облусу, маанилер облусу, курама жана тескери функциялар, жана функция графиктерин өзгөртүү.
</Definition>

## Негизги идеялар

### Көп мүчөлөрдү дифференциялоо

Алгачкы принциптерден xⁿдин градиенти nxⁿ⁻¹ — даража эрежеси. Демек f(x) = 3x³ − 5x² + 2x − 7 болсо, f′(x) = 9x² − 10x + 2, ал эми x = 2де градиент 36 − 20 + 2 = 18.

### Стационардык чекиттер жана табияты

Стационардык чекиттерди табуу үчүн f′(x) = 0 теңдемесин чеч, андан кийин экинчи туундуну же белги диаграммасын колдон: оң экинчи туунду минимумду, терс туунду максимумду билдирет. f(x) = x³ − 3x үчүн f′(x) = 3x² − 3 = 0 болгондо x = ±1, x = −1де максимум, x = 1де минимум болот.

**Негизги термин — Функция:** Ар бир киргизүүгө так бир чыгарууну дайындаган эреже, y = f(x) деп жазылат; уруксат берилген киргизүүлөрдүн жыйындысы — аныкталуу облусу.

<WorkedExample title="Дифференцияла жана градиентти тап">
  f(x) = 3x³ − 5x² + 2x − 7 берилген, f′(x)ти жана x = 2деги градиентти тап.

  Ар бир мүчөгө даража эрежесин колдон: 3x³ → 9x², −5x² → −10x, 2x → 2, ал эми туруктуу сан −7 нөлгө дифференцияланат.
  Демек f′(x) = 9x² − 10x + 2.
  x = 2ни кой: 9(4) − 10(2) + 2 = 36 − 20 + 2 = 18.

  **Жооп:** f′(x) = 9x² − 10x + 2; x = 2де градиент 18.
</WorkedExample>

<ImportantNote title="Типтік каталар">
  - **Туруктуу сан мүчөнү 1ге же xке дифференциялоо** Каалаган туруктуу сандын туундусу 0 — ал эч кандай өзгөрүү кошпойт.
  - **Интегралдоо туруктуу санын жоготуу** Аныкталбаган интеграл + C менен бүтүшү керек; Cнын ар кандай маанилери алгачкы функциялардын бүт үй-бүлөсүн берет.
</ImportantNote>
