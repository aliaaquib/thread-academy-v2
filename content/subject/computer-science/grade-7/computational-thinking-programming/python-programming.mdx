Python is one of the most popular languages in the world — and one of the friendliest for beginners. Everything you planned in flowcharts (sequence, selection) now becomes real, typed code.

<Definition term="Variable">
  A named box that stores a value your program can use and change later.
</Definition>

## Key ideas

### Output and storage

`print()` shows something on screen. A variable stores something for later with `=`:

<CodeBlock lang="Python">
print("Hello, world!")
score = 0
print(score)
</CodeBlock>

This prints `Hello, world!`, stores 0 in `score`, then prints `0`. Text in quotes is called a **string**; numbers need no quotes.

### Input — with a catch

`input()` asks the user to type something. The catch: whatever is typed always comes back as a **string** — even digits. To do maths with it, convert it first:

<CodeBlock lang="Python">
age_text = input("Your age: ")
age = int(age_text)
next_year = age + 1
print(next_year)
</CodeBlock>

`int()` turns the text "12" into the number 12. Without it, `age + 1` would crash — you cannot add 1 to text.

### Selection in code: if-statements

Remember the flowchart diamond? In Python it looks like this:

<CodeBlock lang="Python">
score = 65
if score >= 50:
    print("Pass")
else:
    print("Fail")
</CodeBlock>

The condition uses `==` for "is equal to" (a single `=` would try to store, not compare). The indented lines underneath run only when the condition is true. Indentation is not decoration in Python — it is part of the syntax.

<WorkedExample title="Trace the age checker">
  Code: `age = int(input("Age: "))` then `if age >= 13: print("Teen")` else `print("Child")`. The user types 10.

  Line by line: input shows "Age: " and the user types 10 — as text "10". int() converts it to the number 10, stored in age. The condition `10 >= 13` is false, so the indented print("Teen") is skipped; the else branch runs instead.

  **Answer:** The program prints "Child". If the user had typed 15, the condition would be true and it would print "Teen".
</WorkedExample>

<ImportantNote title="Common mistakes">
  - **= instead of ==** Correction: = stores a value (score = 65); == compares (if score == 65:). Using = inside an if is an error.
  - **Forgetting int() on input** Correction: input() always returns a string — wrap it in int() before any arithmetic, or the program crashes.
  - **Wrong indentation** Correction: the lines under if must be indented (usually 4 spaces). Python uses indentation to decide which lines belong to the if.
</ImportantNote>
