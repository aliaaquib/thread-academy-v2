## Hiragana

Japanese doesn’t use an alphabet — it uses syllabaries. Hiragana’s 46 symbols each represent a syllable: ka, ki, ku, ke, ko. Learn the grid and you’ve cracked the code.

<Definition term="Syllabary">
  A **syllabary** is a writing system where each symbol represents a syllable, not a single sound. Hiragana’s grid: k + (a,i,u,e,o) = か き く け こ.
</Definition>

## Key points

- 46 basic characters in a 5-vowel × consonant grid.
- Dakuten (゛) voices consonants: か ka → が ga.
- Hiragana writes grammar (particles, verb endings) and native words.
- Learn in rows: a, k, s, t, n, h, m, y, r, w — with mnemonics.

<Example title="Reading こんにちは">
  こんにちは (konnichiwa = hello): ko-n-ni-chi-wa. Five symbols, five syllables — every sound visible.
</Example>
