## Arguments

‘You’re wrong because I said so’ is not an argument. ‘All humans are mortal; Socrates is human; therefore Socrates is mortal’ is — the most famous one in history.

<Definition term="Valid argument">
  An argument is **valid** if its conclusion MUST be true whenever its premises are true — regardless of whether the premises actually are true. Validity is about structure; soundness adds true premises.
</Definition>

## Key points

- Premises: the reasons. Conclusion: what they support.
- Valid + true premises = sound argument.
- Deductive: conclusion guaranteed (if valid). Inductive: conclusion probable.
- Most real-world arguments are inductive — evaluate the strength of evidence.

<Example title="Valid but unsound">
  ‘All cats can fly; Felix is a cat; therefore Felix can fly’ is perfectly valid — the logic is flawless. It’s unsound because a premise is false. Logic alone can’t save bad starting points.
</Example>

## Practice

<PracticeQuestions>
  <PracticeItem question="Is this valid? ‘If it rains, the ground gets wet. The ground is wet. Therefore it rained.’" hint="Could the ground be wet another way?">
    Invalid — affirming the consequent. A sprinkler could explain the wet ground.
  </PracticeItem>
  <PracticeItem question="Distinguish validity from soundness." hint="Structure vs structure + truth.">
    Valid: the conclusion follows necessarily from the premises. Sound: valid AND all premises true.
  </PracticeItem>
</PracticeQuestions>

<Summary>
  - Arguments = premises supporting a conclusion.
  - Validity is structural; soundness needs true premises.
  - Deduction guarantees; induction weighs evidence.
  - Test arguments by attacking premises and structure separately.
</Summary>
