Python — один из самых популярных языков в мире и один из самых дружелюбных для новичков. Всё, что ты планировал в блок-схемах (последовательность, выбор), теперь становится настоящим печатным кодом.

<Definition term="Переменная">
  Именованная коробка, которая хранит значение, которое программа может использовать и менять позже.
</Definition>

## Ключевые идеи

### Вывод и хранение

`print()` показывает что-то на экране. Переменная хранит что-то на потом с помощью `=`:

<CodeBlock lang="Python">
print("Hello, world!")
score = 0
print(score)
</CodeBlock>

Это выводит `Hello, world!`, сохраняет 0 в `score`, затем выводит `0`. Текст в кавычках называется **строкой**; числам кавычки не нужны.

### Ввод — с подвохом

`input()` просит пользователя что-нибудь напечатать. Подвох: напечатанное всегда возвращается как **строка** — даже цифры. Чтобы делать с этим математику, сначала преобразуй:

<CodeBlock lang="Python">
colour = input("Enter a colour")
print(colour)
</CodeBlock>

Напечатай «blue» — и он выведет blue. Теперь с числами:

<CodeBlock lang="Python">
age_text = input("Your age: ")
age = int(age_text)
next_year = age + 1
print(next_year)
</CodeBlock>

`int()` превращает текст «12» в число 12. Без него `age + 1` упадёт — нельзя прибавить 1 к тексту.

### Типы данных: четыре вида значений

Каждое значение в Python имеет тип, и тип решает, что с ним можно делать:

- **Целое число** — целое число: 120, 0, -7.
- **Вещественное** (float) — число с дробной частью: 21.3, 1.609.
- **Символ** — один символ: '!', 'V', 'o'.
- **Строка** — один или больше символов: "house", "Victoria Ellis".

Целое число — это целое; у вещественного может быть дробная часть. Символ — только один; строка — один или больше. Путать их — классический источник багов: «10» (строка) и 10 (целое число) выглядят похоже, но ведут себя по-разному.

### Правила именования: допустимые и недопустимые идентификаторы

Имена переменных (идентификаторы) подчиняются строгим правилам:

- Допустимо: colour, totalCost, numA, result
- Недопустимо — начинается с цифры: 2ndPlace
- Недопустимо — есть пробел или точка: my score, my.score
- Недопустимо — это зарезервированное слово: print, if
- Недопустимо — есть дефис: my-score

Нарушишь правило — и Python отвергнет имя. Хорошие имена к тому же осмысленны: totalCost лучше, чем x, когда твой код читает кто-то другой.

### Выбор в коде: условные операторы

Помнишь ромб из блок-схемы? В Python он выглядит так:

<CodeBlock lang="Python">
score = 65
if score >= 50:
    print("Pass")
else:
    print("Fail")
</CodeBlock>

Условие использует `==` для «равно» (одиночный `=` попытался бы сохранить, а не сравнить). Строки с отступом под ним выполняются, только когда условие истинно. Отступы в Python — не украшение, а часть синтаксиса.

Попробуй сам — отредактируй код и нажми «Запустить»:

name = input("Your name: ")

<WorkedExample title="Проследи проверку возраста">
  Код: `age = int(input("Age: "))`, затем `if age >= 13: print("Teen")` else `print("Child")`. Пользователь вводит 10.

  По строкам: input показывает «Age: », и пользователь вводит 10 — текстом «10». int() превращает его в число 10, сохранённое в age. Условие `10 >= 13` ложно, поэтому строка print("Teen") с отступом пропускается; вместо неё выполняется ветка else.

  **Ответ:** Программа выводит «Child». Если бы пользователь ввёл 15, условие было бы истинным, и она вывела бы «Teen».
</WorkedExample>

<WorkedExample title="Прочитай программу деления">
  Эта программа принимает два числа от пользователя, делит первое на второе и выводит ответ:

<CodeBlock lang="Python">
num1 = int(input("First number: "))
num2 = int(input("Second number: "))
answer = num1 / num2
print(answer)
</CodeBlock>

  Проследи с 20 и 4: num1 = 20, num2 = 4, answer = 20 / 4 = 5.0, выводит 5.0.

  **Ответ:** Она выводит 5.0 — и обрати внимание на вещественный результат: деление в Python даёт десятичное число даже для целых чисел.
</WorkedExample>

<ImportantNote title="Типичные ошибки">
  - **= вместо ==** Исправление: = сохраняет значение (score = 65); == сравнивает (if score == 65:). Использовать = внутри if — ошибка.
  - **Забывают int() для input** Исправление: input() всегда возвращает строку — оберни её в int() перед любой арифметикой, иначе программа упадёт.
  - **Неверный отступ** Исправление: строки под if должны быть с отступом (обычно 4 пробела). Python по отступам решает, какие строки принадлежат if.
</ImportantNote>

<Summary>
  - Переменная: именованная коробка, хранящая значение; print() показывает вывод; строки — текст в кавычках.
  - input() всегда возвращает строку — используй int(), чтобы превратить введённые цифры в числа.
  - if/else переносит выбор из блок-схем в код; == сравнивает, = сохраняет; отступ — это синтаксис.
  - Остерегайся: = против ==, забытого int() для input и неверных отступов.
</Summary>
