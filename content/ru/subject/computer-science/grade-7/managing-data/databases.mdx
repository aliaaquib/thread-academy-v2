В школе — тысячи учеников, в магазине — десятки тысяч товаров. Держать эти данные в текстовых файлах было бы хаосом. Решение: **база данных** — система, хранящая данные упорядоченно, с возможностью поиска и безопасно.

<Definition term="База данных">
  Система, хранящая данные упорядоченно в виде таблиц, с быстрым поиском и обновлением.
</Definition>

## Ключевые идеи

### Таблицы, записи, поля

- **Таблица** — данные об одной теме: Ученики, Товары, Выдачи.
- **Запись (строка)** — один элемент в таблице: один ученик, один товар.
- **Поле (столбец)** — одно свойство записи: Имя, ДатаРождения, Цена.

Пример — таблица Ученики:

| УченикID | Имя | Фамилия | Класс |
|---|---|---|---|
| 101 | Али | Юлмаз | 7A |
| 102 | Зейнеп | Кая | 7B |

### Первичный ключ

**Первичный ключ** — это поле, уникально определяющее каждую запись: например, УченикID. Имена двух учеников могут совпасть, а ID — никогда. Без ключа записи не различить.

### Запросы: задаём вопросы

**Запрос** — это вопрос к базе данных: «перечисли учеников класса 7A». Самый распространённый язык запросов — **SQL**:

```sql
SELECT Imya, Familiya FROM Ucheniki WHERE Klass = '7A';
```

Ключевые слова SQL (SELECT, FROM, WHERE) остаются на английском; имена таблиц и полей — собственные имена базы данных.

<WorkedExample title="Напиши запрос">
  Вопрос: «перечисли названия товаров дороже 100». Таблица: Tovary (TovarID, Nazvanie, Tsena).

  ```sql
  SELECT Nazvanie FROM Tovary WHERE Tsena > 100;
  ```

  **Ответ:** SELECT говорит, что показать, FROM — из какой таблицы, WHERE — какие записи выбрать.
</WorkedExample>

<ImportantNote title="Типичные ошибки">
  - **Делать ключом поле имени** Исправление: имена могут повторяться; ключ должен быть уникальным (например, ID).
  - **Пихать всё в одну таблицу** Исправление: каждая таблица — об одной теме; ученики и выдачи — отдельные таблицы.
  - **Переводить ключевые слова SQL** Исправление: SELECT, FROM, WHERE остаются на английском.
</ImportantNote>

## Практика

<PracticeQuestions>
  <PracticeItem question="Что такое таблица, запись и поле?">
    Таблица: данные об одной теме; запись: один элемент (строка); поле: одно свойство элемента (столбец).
  </PracticeItem>
  <PracticeItem question="Зачем нужен первичный ключ?">
    Уникально определяет каждую запись; имена могут повторяться, а ID — нет.
  </PracticeItem>
  <PracticeItem question="Что делает запрос: SELECT Imya FROM Ucheniki WHERE Klass = '7A';">
    Перечисляет имена учеников класса 7A.
  </PracticeItem>
  <PracticeItem question="Предложи две таблицы для библиотеки и напиши их поля.">
    Knigi (KnigaID, Nazvanie, Avtor); Vydachi (VydachaID, KnigaID, UchenikID, Data).
  </PracticeItem>
  <PracticeItem question="Почему база данных лучше текстового файла?">
    Упорядочена, быстро ищется, обновляется и безопасна; текстовый файл с ростом превращается в хаос.
  </PracticeItem>
  <PracticeItem question="Что такое запрос?">
    Вопрос к базе данных; самый распространённый язык — SQL.
  </PracticeItem>
  <PracticeItem question="Напиши запрос, перечисляющий товары дешевле 50. Таблица: Tovary (Nazvanie, Tsena).">
    SELECT Nazvanie FROM Tovary WHERE Tsena &lt; 50;
  </PracticeItem>
</PracticeQuestions>
