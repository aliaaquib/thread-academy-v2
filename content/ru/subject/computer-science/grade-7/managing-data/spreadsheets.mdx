Бюджет, средний балл, результаты эксперимента — везде, где есть числа, есть **электронная таблица**. Сетка из строк и столбцов; в ячейки пишешь числа, формулы считают остальное.

<Definition term="Электронная таблица">
  Сетка из ячеек; ячейки хранят данные, формулы автоматически их вычисляют.
</Definition>

## Ключевые идеи

### Ячейки и адреса

- У каждой ячейки есть **адрес**: буква столбца + номер строки (A1, B3, C10).
- Ячейки хранят числа, текст или даты.
- **Диапазон**: группа ячеек (A1:A10 — от A1 до A10).

### Формулы

Формула начинается с `=` и ссылается на ячейки:

- `=A1+A2` — складывает две ячейки.
- `=SUM(A1:A10)` — суммирует диапазон.
- `=AVERAGE(B1:B20)` — считает среднее.
- `=MAX(C1:C10)` / `=MIN(C1:C10)` — наибольшее/наименьшее.

Прелесть формулы: изменишь A1 — результат обновится сам. Конец ручным подсчётам.

### Диаграммы

Числа в таблице — это скучно; **диаграмма** показывает закономерность: рост продаж, распределение оценок. Выбираешь данные, выбираешь тип диаграммы (столбцы, линия, круговая) — таблица рисует.

<WorkedExample title="Средний балл">
  Оценки в B1:B5: 80, 90, 70, 85, 95. Для среднего в B6 пишем:

  `=AVERAGE(B1:B5)`

  Результат: 84. Изменится одна оценка — среднее обновится само.

  **Ответ:** Формула ссылается на диапазон; при изменении данных результат обновляется сам.
</WorkedExample>

<ImportantNote title="Типичные ошибки">
  - **Писать формулу без `=`** Исправление: формула всегда начинается с `=`.
  - **Вбивать число вручную вместо формулы** Исправление: всё вычисляемое делай формулой — при изменении данных результат обновится.
  - **Неверный диапазон** Исправление: A1:A10 — это от A1 до A10; не пропусти A1:A9.
</ImportantNote>

<Summary>
  - Электронная таблица: сетка ячеек; адрес = столбец + строка.
  - Формулы начинаются с `=`, ссылаются на ячейки (SUM, AVERAGE, MAX, MIN).
  - При изменении данных результат обновляется сам.
  - Диаграммы показывают закономерности.
  - Остерегайся: забывать `=`, считать вручную, неверного диапазона.
</Summary>
