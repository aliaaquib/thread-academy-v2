<Definition term="Сортировка пузырьком">
  Сортируйте списки, многократно меняя местами соседние элементы.
</Definition>

## Ключевые идеи

### Как работает сортировка пузырьком

Один проход идёт по списку, сравнивая каждую соседнюю пару и меняя их местами, когда они стоят не по порядку. После полного прохода самый большой неотсортированный элемент «всплывает» на своё финальное место в конце. Алгоритм повторяет проходы по уменьшающейся неотсортированной части, пока целый проход не пройдёт без обменов — тогда список отсортирован. Каждый проход делает около n сравнений, и может понадобиться до n проходов.

### Сортировка пузырьком проста, но не быстра

Сортировку пузырьком легко понять и закодировать, поэтому её изучают первой — но сравнение каждой пары соседей делает её медленной, O(n²) в худшем случае. Встроенная сортировка Python использует гораздо более умный алгоритм под названием Timsort. На экзаменах знайте шаги сортировки пузырьком и её слабость.

**Термин — сортировка пузырьком:** Сортировка многократным проходом по списку с обменом соседних элементов, стоящих не по порядку, пока обмены не прекратятся.

<WorkedExample title="Разобранный пример: сортировка пузырьком">
  Отсортируйте [4, 2, 5, 1] сортировкой пузырьком, показывая каждый проход.

  Проход 1: сравнить 4,2 → обмен → [2,4,5,1]; сравнить 4,5 → без изменений; сравнить 5,1 → обмен → [2,4,1,5]. Пятёрка всплыла в конец.
  Проход 2: сравнить 2,4 → без изменений; сравнить 4,1 → обмен → [2,1,4,5]. Четвёрка теперь на месте.
  Проход 3: сравнить 2,1 → обмен → [1,2,4,5].
  Проход 4: обменов нет — отсортировано.

  **Ответ:** [1, 2, 4, 5] после 4 проходов.
</WorkedExample>

<ImportantNote title="Типичные ошибки">
  - **Утверждение, что сортировка пузырьком эффективна, потому что её код короткий** Исправление: короткий код — не быстрый код: вложенные сравнения делают сортировку пузырьком O(n²), медленной для больших списков.
  - **Остановка после одного прохода** Исправление: один проход ставит на место только самый большой элемент — продолжайте проходы, пока целый проход не пройдёт без обменов, иначе список не отсортирован.
</ImportantNote>
